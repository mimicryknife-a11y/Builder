# Burger Builder
Тема: паттерн "Строитель"

### Как работает разделение ролей
**Builder** - собирает конкретные бургеры (классический, острый, веганский). Каждый знает только свой рецепт.
**DirectorCashier** - принимает заказ и говорит строителю, что делать. Может добавить овощи, если попросили.

### Почему это удобно для фуд-аппов
1. **Меньше ошибок** - Кассир не зависит от бургеров, а бургеры от кассира. Поэтому меньше проблем
2. **Легко добавлять новое** - Если хотите новый бургер просто добавьте нового строителя
3. **Гибкость** - Можно легко менять состав
4. **Понятный код** - Каждый отвечает за своё дело
